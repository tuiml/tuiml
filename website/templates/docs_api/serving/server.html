Model Serving Server - FastAPI REST API for serving trained models.

Provides HTTP endpoints for loading models, making predictions, and managing the model serving lifecycle.

Usage: # Serve a single model from tuiml.serving import serve serve("model.pkl", port=8000)

# Or create a custom app from tuiml.serving import ModelServer server = ModelServer() server.load_model("my_model", "model.pkl") app = server.create_app() # Run with uvicorn: uvicorn app:app
