tuiml list-files [OPTIONS]

List the algorithm source files available on this machine.

Reports the path, category and metadata of every algorithm file, both the ones shipped with TuiML and the ones you have written yourself. Run this before tuiml read-algorithm or tuiml search-source to see what exists and to find the exact name to pass to them.

List every algorithm file:

bash 
$ tuiml list-files

List only the algorithms you have written:

bash 
$ tuiml list-files --no-builtin

Get the listing as raw JSON for scripting:

bash 
$ tuiml list-files --json-output

Options

--builtin/--no-builtin
= True
Include built-in tuiml algorithm files.
--user/--no-user
= True
Include user-authored algorithm files.
--json-output
flag
Output raw JSON
