Information-theoretic evaluation metrics.

These metrics are used by Weka for measuring information gain, entropy, etc. Equivalent to Weka's information-theoretic evaluation methods.

entropy(labels: np.ndarray, base: Optional[float]=None) -> float

Calculate entropy of a label distribution.

Equivalent to Weka's information-theoretic calculations.

Args: labels: Array of class labels base: Logarithm base (None for natural log, 2 for bits) Returns: Entropy value Example: >>> entropy([0, 0, 1, 1]) 0.693... # ln(2) >>> entropy([0, 0, 1, 1], base=2) 1.0 # 1 bit

Calculate symmetrical uncertainty (normalized mutual information).
