C++ backend wrappers for tree operations.

This module provides Python wrappers around the compiled C++ tree functions (splitting, building, prediction). All tree algorithms should import these wrappers instead of calling _cpp_ext.tree directly.

C++ is a hard requirement -- there are no Python fallbacks here. Pure-Python tree utilities (criteria helpers, pruning, etc.) remain in _core/ and are used for leaf-node logic, pruning, and criteria that the C++ backend does not yet support.
