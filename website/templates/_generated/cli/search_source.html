tuiml search-source [OPTIONS]

Search algorithm source files for a regular expression.

Greps the source of built-in and user-authored algorithms and returns every matching line with its file path and line number. Use it to pinpoint a function, attribute or piece of logic before reading or editing a file. Narrow the search with --name to target a single user algorithm, or with --no-builtin / --no-user to restrict the scope.

Find every implementation of a method:

bash 
$ tuiml search-source --query "def partial_fit"

Search only the algorithms you have written:

bash 
$ tuiml search-source --query "gini" --no-builtin

Search inside one algorithm:

bash 
$ tuiml search-source --query "self._tree" --name MyTreeClassifier

Options

--query
str required
Regular expression to search for.
--name
str
Scope the search to one user algorithm by name. Omit to search all.
--builtin/--no-builtin
= True
Search built-in algorithm files.
--user/--no-user
= True
Search user-authored algorithm files.
--json-output
flag
Output raw JSON
