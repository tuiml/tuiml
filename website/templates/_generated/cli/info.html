tuiml info [OPTIONS]

Show which TuiML is installed, and where.

Prints the installed version, how it was installed, the package and Python paths in use, and the host platform. Unless --no-check is passed it also queries PyPI for the latest release and flags whether an upgrade is available. Start here when diagnosing a "wrong version" problem, then use tuiml update to upgrade.

Show installation details and check for a newer release:

bash 
$ tuiml info

Skip the network round-trip:

bash 
$ tuiml info --no-check

Machine-readable output, for scripts:

bash 
$ tuiml info --json

Options

--no-check
flag
Skip the PyPI latest-version lookup. Faster, and works offline.
--json
flag
Emit raw JSON instead of the human-readable table.
