train

Line 286
train(algorithm: Union[str, Dict]=None, data: Union[str, pd.DataFrame, np.ndarray]=None, target: Union[str, np.ndarray]=None, *, preprocessing: Optional[Union[str, List[Union[str, Dict]]]]=None, feature_selection: Optional[Union[str, Dict]]=None, test_size: float=0.2, stratify: bool=True, random_state: Optional[int]=42, cv: Optional[int]=None, metrics: Union[List[str], str]='auto', return_model: bool=True, return_predictions: bool=False, return_probabilities: bool=False, preset: Optional[str]=None, verbose: bool=False, **kwargs) -> WorkflowResult

Train a machine learning model with a complete workflow.

This is the main high-level function for training models in TuiML. It supports multiple flexible input formats for maximum convenience and is designed to be LLM-friendly for automated ML workflows.

Parameters

algorithm
str or dict

Algorithm specification. Accepts flexible formats:

  • "RandomForestClassifier" Class name as string
  • {"name": "RandomForestClassifier", "n_trees": 100} Dict with params
data
str, DataFrame, or ndarray

Training data source:

  • "path/to/file.csv" Path to data file
  • DataFrame Pandas DataFrame
  • ndarray Numpy array
target
str or ndarray

Target specification:

  • "column_name" Column name in DataFrame
  • ndarray Target array
preprocessing
str, list, or None = None

Preprocessing pipeline specification:

  • "MinMaxScaler" Single preprocessor name
  • ["SimpleImputer", "MinMaxScaler"] List of names
  • [{"name": "SimpleImputer", "strategy": "mean"}] List of dicts
  • "standard" Preset name
  • None No preprocessing
feature_selection
str, dict, or None = None

Feature selection specification:

  • "SelectKBestSelector" Class name
  • {"name": "SelectKBestSelector", "k": 10} Dict with params
  • None No feature selection
test_size
float = 0.2
Proportion of data reserved for testing.
stratify
bool = True
Whether to maintain class distribution in train/test split.
random_state
int or None = 42
Random seed for reproducibility.
cv
int or None = None
Number of cross-validation folds. If set, uses CV instead of holdout.
metrics
str or list = "auto"

Metrics to compute:

  • "auto" Automatically select based on task type
  • ["accuracy", "f1", "roc_auc"] List of metric names
  • "accuracy" Single metric name
return_model
bool = True
Whether to include the trained model in the result.
return_predictions
bool = False
Whether to include test set predictions in the result.
return_probabilities
bool = False
Whether to include prediction probabilities in the result.
preset
str or None = None

Preprocessing preset name:

  • "minimal" No preprocessing
  • "fast" Basic imputation only
  • "standard" Impute + Normalize + Encode
  • "full" All preprocessing + feature selection
  • "imbalanced" Standard + SMOTESampler
verbose
bool = False
Whether to print progress information.
**kwargs
Additional algorithm parameters passed directly to the model (e.g., n_trees=100, max_depth=10).

Returns

WorkflowResult

Result object containing:

  • model Trained model instance
  • metrics Dict of computed metrics
  • predictions Test predictions (if requested)
  • probabilities Prediction probabilities (if requested)
  • metadata Additional workflow metadata

Examples

Simplest usage with just algorithm and data:

PYTHON 
>>> result = tuiml.train("RandomForestClassifier", "iris.csv", "class")

With algorithm parameters as kwargs:

PYTHON 
>>> result = tuiml.train(
...     "RandomForestClassifier",
...     "iris.csv",
...     "class",
...     n_trees=100,
...     max_depth=10
... )

Using a preprocessing preset:

PYTHON 
>>> result = tuiml.train(
...     "RandomForestClassifier",
...     "iris.csv",
...     "class",
...     preset="standard",
...     n_trees=100
... )

With explicit preprocessing pipeline:

PYTHON 
>>> result = tuiml.train(
...     "RandomForestClassifier",
...     "iris.csv",
...     "class",
...     preprocessing=["SimpleImputer", "MinMaxScaler"],
...     feature_selection="SelectKBestSelector",
...     n_trees=100
... )

Cross-validation:

PYTHON 
>>> result = tuiml.train(
...     "SVM",
...     "data.csv",
...     "label",
...     preprocessing="standard",
...     cv=10,
...     kernel="rbf",
...     C=1.0
... )

run(config: Union[Dict, str]) -> WorkflowResult

Run a complete workflow from a configuration dict or JSON file.

This function enables you to load and execute ML workflows from configuration dictionaries or JSON files, making it ideal for programmatic workflows and LLM-generated configurations.

Parameters

config
dict or str

Configuration specification:

  • dict Configuration dictionary
  • str Path to JSON configuration file
Required keys: algorithm, data, target Optional keys: preprocessing, feature_selection, cv, metrics, etc.

Returns

WorkflowResult
Result object with model, metrics, and metadata.

Examples

From a configuration dictionary:

PYTHON 
>>> config = {
...     "algorithm": "RandomForestClassifier",
...     "data": "iris.csv",
...     "target": "class",
...     "preprocessing": "standard",
...     "n_trees": 100,
...     "cv": 10
... }
>>> result = tuiml.run(config)

From a JSON file:

PYTHON 
>>> result = tuiml.run("config.json")

LLM-generated configuration:

PYTHON 
>>> llm_config = {
...     "algorithm": {"name": "RandomForestClassifier", "n_trees": 100},
...     "data": "data.csv",
...     "target": "label",
...     "preprocessing": ["SimpleImputer", "Normalize"],
...     "feature_selection": {"name": "SelectKBestSelector", "k": 10},
...     "cv": 5
... }
>>> result = tuiml.run(llm_config)

experiment

Line 699
experiment(algorithms: Union[Dict[str, Any], List[Union[str, tuple, Any]]], datasets: Union[Dict[str, tuple], List[Union[str, Dict]]], *, preprocessing: Optional[Union[List[Dict], str]]=None, cv: int=10, metrics: List[str]=None, n_jobs: int=1, verbose: int=0, progress_callback: Optional[Callable]=None)

Run experiments to compare multiple algorithms on multiple datasets.

This function facilitates large-scale benchmarking by executing multiple algorithms across various datasets using cross-validation. It uses exact class names for maximum scalability and transparency.

Parameters

algorithms
dict or list

Algorithm specifications. Accepts flexible formats:

  • {"RF": RandomForestClassifier(), "SVM": SVM()} Dict of name to instance
  • ["RandomForestClassifier", "SVM"] List of class names (uses defaults)
  • [("RF", {"n_trees": 100}), ...] List of (name, params) tuples
datasets
dict or list

Dataset specifications:

  • {"iris": (X, y)} Dict of name to (features, target) tuples
  • ["iris", "wine"] List of dataset names (loads from registry)
  • [{"path": "data.csv", "target": "class"}, ...] List of config dicts
preprocessing
str, list, or None = None
Preprocessing config or preset name to apply to all datasets.
cv
int = 10
Number of cross-validation folds.
metrics
list of str
Metrics to compute for each algorithm/dataset pair. Defaults to ["accuracy"] for classification.
n_jobs
int = 1
Number of parallel jobs to run. Use -1 for all available CPUs.
verbose
int = 0
Verbosity level for progress reporting.

Returns

Experiment
Experiment object containing results, comparison tables, and statistical tests (e.g., Nemenyi test).

Examples

Compare algorithms using class names:

PYTHON 
>>> exp = tuiml.experiment(
...     algorithms=["RandomForestClassifier", "SVM", "NaiveBayesClassifier"],
...     datasets=["iris", "wine"],
...     cv=10
... )

With specific model parameters and custom metrics:

PYTHON 
>>> exp = tuiml.experiment(
...     algorithms={
...         "RF_100": RandomForestClassifier(n_trees=100),
...         "SVM_RBF": SVM(kernel="rbf")
...     },
...     datasets={"iris": (X_iris, y_iris)},
...     metrics=["accuracy", "f1_macro"]
... )
>>> print(exp.summary())

serve

Line 1075
serve(model_or_path, host: str='127.0.0.1', port: int=8000, model_id: str='default', background: bool=True)

Serve a trained model via REST API.

Accepts a file path, a WorkflowResult, or a model object and starts a uvicorn server exposing prediction endpoints.

Parameters

model_or_path
str, WorkflowResult, or model object

The model to serve:

  • str Path to a saved model file
  • WorkflowResult Result from ``Workflow.run()`` or ``train()``
  • •model object — Any object with a predict() method
host
str = "127.0.0.1"
Host to bind the server to.
port
int = 8000
Port to listen on.
model_id
str = "default"
Identifier for the model in the server.
background
bool = True
If True, run the server in a daemon thread and return immediately. If False, block until the server is stopped.

Returns

dict or None
If background=True, returns a dict with server_id, url, and endpoints. If background=False, blocks and returns None.

Examples

Serve from a WorkflowResult:

PYTHON 
>>> result = tuiml.train("NaiveBayesClassifier", "iris", "class")
>>> info = tuiml.serve(result, port=9999)
>>> print(info["url"])
http://127.0.0.1:9999

Serve from a file path:

PYTHON 
>>> info = tuiml.serve("model.pkl", port=8000)

Blocking mode:

PYTHON 
>>> tuiml.serve(result, background=False)
