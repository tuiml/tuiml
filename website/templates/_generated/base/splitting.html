BaseSplitter

Base classes for data splitting.

Defines BaseSplitter, the interface implemented by the train/test splitters in tuiml.evaluation.splitting (KFold, StratifiedKFold, etc.).

BaseSplitter

class base.splitting.BaseSplitter(ABC)

Base class for all data splitters.

All splitters implement the split() method that yields (train_indices, test_indices) tuples.
