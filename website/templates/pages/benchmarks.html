Methodology

Protocol
[+]Datasets: 51 tabular datasets from TabArena v0.1 (38 classification, 13 regression)
[+]Frameworks: TuiML, scikit-learn, Weka (python-weka-wrapper3)
[+]Algorithms: only those available in all three libraries
[+]Validation: stratified 10-fold cross-validation (shuffled, fixed seed), folds identical across frameworks; scores are mean ± std over the 10 folds
[+]Preprocessing: shared impute + scale + one-hot; Naive Bayes uses ordinal-encoded / quantile-binned features with each library's native categorical NB
[+]Hyperparameters: library defaults (Weka runs its native variants)
[+]Metrics: Accuracy / R², training time, peak memory
Environment
[+]TuiML: v0.1.9
[+]scikit-learn: v1.8.0
[+]Weka: python-weka-wrapper3 0.3.2 (Java 21)
[+]Each experiment: isolated process, single-threaded
