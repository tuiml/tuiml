Installation

One-line install (recommended)

Installs uv and TuiML globally. Works on macOS and Linux (including WSL).

TERMINAL 
curl -fsSL https://tuiml.ai/install.sh | bash

Via pip / uv

If you already have a Python environment.

TERMINAL 
# Using pip
pip install tuiml

# Using uv
uv add tuiml

From source (development)

TERMINAL 
git clone https://github.com/tuiml/tuiml.git
cd tuiml
uv sync          # Install dependencies
uv run pytest    # Run tests

AI Agent Setup

Connect TuiML to your favourite AI coding tool. Install the Skill file so your agent understands TuiML patterns, and connect the MCP server so it can run algorithms directly.

Recommended: One-command setup

Auto-detects Claude Desktop, Claude Code, Cursor, and more. Wires them up safely (with backups).

tuiml setup

Want to see what would change first? Run tuiml setup --list. Need a specific client? tuiml setup --client openclaw. Use --yes for non-interactive setup.

Integrate with OpenClaw

The featured CLI agent partner. Routes any agent inside OpenClaw to all 200+ TuiML tools.

Option 1 — tuiml setup
tuiml setup --client openclaw

Registers TuiML with OpenClaw's MCP registry.

Option 2 — OpenClaw CLI
openclaw mcp set tuiml '{"command":"tuiml-mcp"}' && openclaw gateway restart

Native OpenClaw command — scroll to see full line.

Manual config

If you prefer, add this block to ~/.openclaw/openclaw.json by hand:

{
  "mcp": {
    "servers": {
      "tuiml": { "command": "tuiml-mcp" }
    }
  }
}

Verify: openclaw mcp list should show tuiml.

Try it: openclaw chat "train a random forest on iris and report accuracy using TuiML"

Advanced setup: if your client is not covered by tuiml setup, follow the manual steps below from a source checkout.

Integrate with NVIDIA NemoClaw

NemoClaw sandboxes are locked down by default. Use the PyPI policy preset, then install TuiML inside the sandbox.

Host
Allow PyPI

Grant package-install access before entering the sandbox.

Sandbox
Install TuiML

Create a venv in the persistent OpenClaw workspace.

OpenClaw
Register MCP

Register the venv's MCP command with OpenClaw.

# On the host
nemoclaw <sandbox-name> policy-add pypi --yes
nemoclaw <sandbox-name> connect

# Inside the sandbox
python -m venv /sandbox/.openclaw/workspace/tuiml_venv
. /sandbox/.openclaw/workspace/tuiml_venv/bin/activate
pip install tuiml
openclaw mcp set tuiml '{"command":"/sandbox/.openclaw/workspace/tuiml_venv/bin/tuiml-mcp"}'
openclaw gateway restart

Why PyPI? The tuiml.ai/install.sh curl installer can be blocked by NemoClaw policy. The built-in pypi preset is the simpler supported path.

Verify: after setup, openclaw mcp list should show tuiml.

Skill File

A knowledge file that teaches your AI agent TuiML's API, patterns, base classes, and docstring conventions.

MCP Server

A local server that exposes 200+ ML tools (train, evaluate, preprocess, etc.) your AI agent can call directly.

Step 1 — Install the Skill File

terminal
mkdir -p .cursor/rules
cp path/to/tuiml/tuiml/agent/SKILL.md .cursor/rules/tuiml.md

Cursor auto-loads all .md files from .cursor/rules/ as project context.

Step 2 — Connect the MCP Server

Create or edit .cursor/mcp.json in your project root:

.cursor/mcp.json
{
  "mcpServers": {
    "tuiml": {
      "command": "tuiml-mcp"
    }
  }
}

Restart Cursor to activate. The agent can now call 200+ ML tools.

Step 1 — Install the Skill File

terminal
mkdir -p ~/.claude/skills/tuiml
cp path/to/tuiml/tuiml/agent/SKILL.md ~/.claude/skills/tuiml/SKILL.md

Claude Code loads skill files from ~/.claude/skills/<name>/SKILL.md automatically.

Step 2 — Connect the MCP Server

terminal
claude mcp add tuiml -- tuiml-mcp

That's it. Claude Code will discover and use TuiML tools in your next session.

Step 1 — Add Custom Instructions

Go to Settings → Personalization → Custom Instructions and paste the contents of Skill.md, or create a project and add it as a project file.

terminal
# Copy the skill content to clipboard (macOS)
cat path/to/tuiml/tuiml/agent/SKILL.md | pbcopy

Step 2 — Connect MCP (Remote)

ChatGPT supports remote MCP servers via Developer Mode. Enable it in Settings, then go to Connectors → Create → MCP and enter your hosted TuiML MCP server URL.

ChatGPT requires a remotely-hosted MCP server (HTTP/SSE). See the model serving tutorial for hosting instructions.

Claude Desktop / Other Desktop Apps

Desktop apps that support MCP typically use a JSON configuration file.

Step 1 — Install the Skill File

Add the contents of Skill.md to the app's custom instructions or project knowledge feature.

Step 2 — Connect the MCP Server

Edit the app's MCP configuration file (e.g. claude_desktop_config.json):

config.json
{
  "mcpServers": {
    "tuiml": {
      "command": "tuiml-mcp"
    }
  }
}

Restart the app to connect. The agent will discover all TuiML tools automatically.

Requirements

pip install tuiml includes the core ML library, CLI, and local MCP server. Agent clients such as Cursor, Claude, ChatGPT, or OpenClaw are configured separately.

Core

  • Python 3.10+
  • NumPy, SciPy, pandas
  • joblib
  • Click CLI
  • requests

Included

  • matplotlib, seaborn
  • XGBoost, LightGBM, CatBoost
  • MCP server for LLM agents
  • FastAPI, Uvicorn, Pydantic
  • bigtree
