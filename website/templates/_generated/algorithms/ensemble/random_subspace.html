RandomSubspaceClassifier

class algorithms.ensemble.random_subspace.RandomSubspaceClassifier(Classifier)

RandomSubspaceClassifier for feature subspace ensemble classification.

The Random Subspace method builds an ensemble of classifiers where each classifier is trained on a random subset of input features, creating diversity through feature subsampling rather than data subsampling.
Constructor 
__init__(
    self,
    base_classifier: Any = 'C45TreeClassifier',
    n_estimators: int = 10,
    subspace_size: float = 0.5,
    random_state: Optional[int] = None,
    n_jobs: int = 1,
)

Overview

The algorithm proceeds as follows:

  1. For each of T ensemble members:
a. Randomly select d features from the full D-dimensional feature space b. Train a base classifier using only the selected feature subspace c. Store the classifier along with its selected feature indices
  1. To predict, aggregate predictions from all T classifiers via majority vote

Theory

Each subspace \mathcal{F}_t is a random subset of the feature set \{1, 2, \ldots, D\}:

\mathcal{F}_t \subset \{1, \ldots, D\}, \quad |\mathcal{F}_t| = d

where d = \lfloor D \cdot \text{subspace\_size} \rfloor when subspace_size is a float.

The final prediction uses majority voting across subspace classifiers:

H(x) = \arg\max_{k} \sum_{t=1}^{T} \mathbb{1}[h_t(x_{\mathcal{F}_t}) = k]

The ensemble achieves diversity because each classifier operates in a different projection of the feature space, reducing the correlation \rho between base learners.

Notes

Complexity:

  • Training: O(T \cdot n \cdot C_{\text{base}}(d)) where T = n_estimators,
n = number of samples, C_{\text{base}}(d) = base classifier complexity on d features
  • Prediction: O(T \cdot C_{\text{predict}}(d)) per sample
When to use RandomSubspaceClassifier:
  • High-dimensional datasets where feature subsets carry discriminative information
  • When you want to reduce overfitting through feature decorrelation
  • As an alternative to bagging when data size is limited
  • When combined with decision trees, provides a Random-Forest-like approach

RandomSubspaceRegressor for feature subspace ensemble regression.

The Random Subspace method builds an ensemble of regressors where each regressor is trained on a random subset of input features, creating diversity through feature subsampling rather than data subsampling.
Constructor 
__init__(

    random_state: Optional[int] = None,

)

Overview

The algorithm proceeds as follows:

  1. For each of T ensemble members:
a. Randomly select d features from the full D-dimensional feature space b. Train a base regressor using only the selected feature subspace c. Store the regressor along with its selected feature indices
  1. To predict, average predictions from all T regressors

Theory

Each subspace \mathcal{F}_t is a random subset of the feature set \{1, 2, \ldots, D\}:

\mathcal{F}_t \subset \{1, \ldots, D\}, \quad |\mathcal{F}_t| = d

where d = \lfloor D \cdot \text{subspace\_size} \rfloor when subspace_size is a float.

The final prediction averages across subspace regressors:

H(x) = \frac{1}{T} \sum_{t=1}^{T} h_t(x_{\mathcal{F}_t})
