Local component registry for TuiML.

Provides the local algorithm/feature/preprocessor registry used by @classifier, @regressor, @transformer decorators across the library, plus the shared ComponentType enum and Registrable mixin.

Local component registration:

python 
from tuiml.registry import registry
python 
@registry.register("classifier")
class MyClassifier:
    pass
python 
model = registry.create("MyClassifier", param=value)

Registry

class registry.Registry

Local registry for TuiML components.

Provides discovery, registration, and instantiation of local components. Supports plugins from external packages.
python 
>>> from tuiml.registry import registry
>>> # Register a custom algorithm
>>> @registry.register("classifier")
... class MyClassifier:
...     pass
>>> # List all classifiers
>>> registry.list(ComponentType.CLASSIFIER)
>>> # Get a component by name
>>> cls = registry.get("MyClassifier")
