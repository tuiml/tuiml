Shared helpers for the agent framework adapters.

Every adapter in tuiml.agent.* (langchain, openai, anthropic, pydantic_ai, crewai, …) derives its tool list from the same source of truth — the WORKFLOW_TOOLS dict in tuiml.agent.tools — and routes invocations through execute_tool. This module holds the bits that don't belong to any one framework: the canonical tool iterator, the JSON-Schema → Pydantic model converter, the framework-agnostic callable adapter, and the bundled system prompt (SKILL.md) loader.
