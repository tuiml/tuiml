OneRuleClassifier

class algorithms.rules.oner.OneRuleClassifier(Classifier)

One Rule classifier using the single best attribute for minimum-error classification.

OneRuleClassifier is a simple, accurate classification algorithm that generates one rule for each attribute in the training data and selects the rule with the smallest error rate. For numeric attributes, it uses supervised discretization to create rules.

Overview

The algorithm selects the single most predictive attribute as follows:

  1. For each attribute in the dataset:
a. If numeric, discretize into buckets of at least min_bucket_size instances using class-boundary splits b. For each unique value (or bucket), assign the majority class c. Compute the total error rate for this attribute
  1. Select the attribute with the lowest error rate
  2. At prediction time, look up the value of the selected attribute and
return the associated majority class

Theory

For each attribute a, the error rate is computed as:

\text{Error}(a) = 1 - \frac{1}{n} \sum_{v \in \text{vals}(a)} \max_{c \in C} n_{v,c}

where n_{v,c} is the number of instances with attribute value v belonging to class c, and the best attribute is:

a^* = \arg\min_{a \in A} \text{Error}(a)

For numeric attributes, supervised discretization creates breakpoints where the majority class changes, subject to a minimum bucket size constraint.

Notes

Complexity:

  • Training: O(n \cdot m \cdot \log(n)) where n = number
of samples and m = number of features (sorting for discretization dominates)
  • Prediction: O(m) per sample (single attribute lookup)
When to use OneRuleClassifier:
  • As a simple interpretable baseline
  • When one attribute is expected to be highly predictive
  • For quick feature importance assessment
  • When the simplest possible model is desired for explanation

Basic usage for single-attribute classification:

python 
>>> from tuiml.algorithms.rules import OneRuleClassifier
>>> import numpy as np
>>>
>>> # Create sample data
>>> X_train = np.array([[1, 2], [2, 3], [3, 1], [4, 3], [5, 2]])
>>> y_train = np.array([0, 0, 1, 1, 1])
>>>
>>> # Fit the model
>>> clf = OneRuleClassifier(min_bucket_size=6)
>>> clf.fit(X_train, y_train)

>>> predictions = clf.predict(X_train)
