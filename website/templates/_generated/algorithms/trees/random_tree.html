RandomTreeClassifier

class algorithms.trees.random_tree.RandomTreeClassifier(Classifier)

Random Tree classifier - a single randomized decision tree.

RandomTreeClassifier is a decision tree that considers a random subset of attributes at each node. This randomization, combined with growing the tree to full depth, makes it suitable as a base learner for Random Forest ensembles and other bagging methods.
Constructor 
__init__(
    self,
    max_features: Any = 'sqrt',
    max_depth: Optional[int] = None,
    min_samples_split: int = 2,
    min_samples_leaf: int = 1,

Overview

The algorithm builds a fully-grown randomized tree:

  1. At each node, randomly select k features from the full set
  2. Among the selected features, evaluate all candidate split points
using Gini impurity reduction
  1. Choose the feature and threshold that maximize impurity decrease
  2. Recursively partition the data until stopping criteria are met
  3. No pruning is applied -- the tree is grown to full depth

Theory

The Gini impurity at a node with c classes is:

Gini(S) = 1 - \sum_{i=1}^{c} p_i^2

The impurity decrease for a split on attribute A at threshold t is:

\Delta Gini = Gini(S) - \frac{|S_L|}{|S|} Gini(S_L) - \frac{|S_R|}{|S|} Gini(S_R)

The number of candidate features k at each node is:

  • 'sqrt': k = \lfloor \sqrt{m} \rfloor
  • 'log2': k = \lfloor \log_2(m) \rfloor
where m is the total number of features.

Notes

Complexity:

  • Training: O(n \cdot k \cdot \log(n)) where n = samples,
k = max_features
  • Prediction: O(\log(n)) per sample (average tree depth)
  • Space: O(n) for a fully-grown tree in the worst case
When to use RandomTreeClassifier:
  • As a base learner inside Random Forest or bagging ensembles
  • When you need a single diverse tree for ensemble diversity
  • When fast training on high-dimensional data is required
  • Not recommended as a standalone classifier (high variance)

RandomTreeRegressor

class algorithms.trees.random_tree.RandomTreeRegressor(Regressor)

Random Tree regressor - a single randomized regression tree.

RandomTreeRegressor is a regression tree that considers a random subset of features at each node and uses variance reduction (MSE reduction) as the splitting criterion. Each leaf predicts the mean target value of its samples. Designed as a base learner for Random Forest regression ensembles.
Constructor 
__init__(
    self,
    max_features: Any = 'sqrt',
    max_depth: Optional[int] = None,
    min_samples_split: int = 2,
    min_samples_leaf: int = 1,
    random_state: Optional[int] = None,
)

Overview

The algorithm builds a fully-grown randomized regression tree:

  1. At each node, randomly select k features from the full set
  2. Among the selected features, evaluate all candidate thresholds
using variance reduction (MSE decrease)
  1. Choose the feature and threshold that maximize variance reduction
  2. Recursively partition until stopping criteria are met
  3. No pruning is applied -- the tree is grown to full depth

Theory

The variance (MSE) at a node with targets y_1, \dots, y_n is:

\text{MSE}(S) = \frac{1}{|S|} \sum_{i=1}^{|S|} (y_i - \bar{y})^2

The variance reduction for a split is:

\Delta \text{MSE} = \text{MSE}(S) - \frac{|S_L|}{|S|} \text{MSE}(S_L) - \frac{|S_R|}{|S|} \text{MSE}(S_R)
