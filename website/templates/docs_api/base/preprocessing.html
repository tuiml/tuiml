Preprocessor

class base.preprocessing.Preprocessor(Registrable, ABC)

Abstract base class for all data preprocessing operations.

Defines a consistent API for fitting parameters to training data and applying those parameters to transform data.
Constructor 
__init__(
    self,
)

Overview

Preprocessors are the building blocks of data pipelines. They can be unsupervised (only X) or supervised (X and y).

Notes

Subclasses must implement :meth:fit and :meth:transform.

Filter

class base.preprocessing.Filter(Preprocessor)

Base class for filter-type preprocessors.

Filters typically modify the data by removing or replacing values without changing the underlying math of the feature space (e.g., handling missing values, removing outliers).

Transformer

class base.preprocessing.Transformer(Preprocessor)

Base class for feature transformers.

SupervisedTransformer

class base.preprocessing.SupervisedTransformer(Transformer)

Base class for supervised feature transformers.

Unlike standard transformers, supervised transformers utilize the target labels (y) during the :meth:fit process to optimize the transformation (e.g., Target Encoding, Decision-Tree Binning).
