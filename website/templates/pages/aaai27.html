Teaching an Agent to Do Transparent, Reproducible Machine Learning

A hands-on lab (quarter day, 1 h 45 min). Connect an AI assistant to a local machine learning runtime over the Model Context Protocol, drive a complete modelling workflow in plain English, then reproduce every step yourself from the run log.

Overview

As AI agents become more capable, machine learning practitioners are offloading more of their modelling work to them. The agent usually answers with a block of throwaway Python that nobody checks: the result cannot be reproduced and the evaluation cannot be audited.

This lab teaches the alternative. Instead of letting the assistant write code, we expose an open-source machine learning library, TuiML, to it as a set of typed tools over the Model Context Protocol (MCP). The agent calls ordinary, schema-checked library functions, every call is logged, and every action can be replayed afterwards. The session is built around one claim that attendees verify for themselves rather than accept on trust: agent-driven data science can be fully transparent and reproducible, provided the agent is restricted to the same function calls a human would make.

What you will learn

[+]Connect an MCP-capable assistant to a local Python ML runtime and inspect which capabilities it can see.
[+]Drive a complete supervised learning workflow in plain English: profiling, preprocessing, cross-validated training, and evaluation.
[+]Reproduce: recover the exact sequence of library calls from the run log, re-execute it in a notebook, and confirm the metrics match to the digit.
[+]Go further: hyperparameter search, ensembling, and revising a model in response to its own evaluation.
[+]Judge: attach a feature attribution and a conformal prediction interval to a single prediction and decide whether the model is fit to deploy.
[+]Know the limits: where this workflow breaks down and what should still be left to a human.

Prerequisites

None beyond a laptop. Python is helpful but not required: no modelling code is written by attendees, and the notebook is supplied ready to run. No machine learning, mathematics, or agent background is assumed; tool calling and MCP are built up from zero.

[+]Laptop with Wi-Fi. No GPU needed; the datasets are small.
[+]Python 3.10+ and an environment tool such as uv or conda. TuiML installs with pip install tuiml.
[+]Any MCP-capable assistant. Free and open clients will be listed in the setup guide, so no paid subscription is required.
[+]Fallback: pre-configured cloud sandboxes are provided, so a broken laptop never costs you the session.
