LangChain / LangGraph adapter — TuiML tools as ``StructuredTool`` objects.

LangGraph consumes LangChain tools directly (ToolNode(tools=[...])), so this module covers both frameworks.

Example ------- >>> from tuiml.agent.langchain import get_tools, system_prompt >>> from langgraph.prebuilt import create_react_agent >>> from langchain_anthropic import ChatAnthropic >>> >>> agent = create_react_agent( ... model=ChatAnthropic(model="claude-sonnet-4-6"), ... tools=get_tools(), ... prompt=system_prompt(), ... ) >>> agent.invoke({"messages": [("user", "Train a random forest on iris")]})
