Convenience loaders for bundled datasets outside classification and regression.

Covers the two remaining task types shipped with TuiML: market-basket data for association rule mining (load_supermarket) and the Reuters text collections (load_reuters_corn, load_reuters_grain), which come as separate train and test files.

Every loader here is also reachable by name through load_dataset.

python 
>>> from tuiml.datasets import load_supermarket, load_reuters_corn
>>> transactions = load_supermarket()
>>> test = load_reuters_corn(split='test')
