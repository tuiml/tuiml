Utility modules and helper functions.

The tuiml.utils module provides common infrastructure for model management, including serialization, checkpointing, and cross-platform export tools.

Overview

  1. Serialization: High-level functions for saving and loading models
with metadata tracking (pickle, joblib, compressed).
  1. Checkpointing: Automated management of model snapshots during
long-running training tasks.
  1. Interoperability: Exporters for industry-standard formats like
ONNX.
