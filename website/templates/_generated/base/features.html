FeatureSelector

class base.features.FeatureSelector(FeatureMethod)

Base class for feature selection algorithms.

Feature selection identifies and preserves the most relevant subset of existing features based on statistical significance, model importance, or information theory.
Constructor 
__init__(
    self,
    k: Optional[int] = None,
    threshold: Optional[float] = None,
)

Overview

Unlike extraction, selection does not create new features; it simplifies the model by pruning irrelevant or redundant inputs.

Parameters

k
int
The number of top-scoring features to retain.
threshold
float
The minimum score required for a feature to be selected.
