class algorithms.rules.m5rules.M5ModelRulesRegressor(Regressor)

M5 Model Rules for rule-based regression using linear models at each rule leaf.

M5ModelRulesRegressor generates regression rules from M5 model trees. Each rule consists of a set of conditions and a linear model for prediction, combining the interpretability of rules with the accuracy of linear regression.

Overview

The algorithm builds regression rules via a separate-and-conquer strategy:

  1. Compute the global standard deviation of the target variable
  2. While uncovered instances remain:
a. Find the best split using Standard Deviation Reduction (SDR) b. Recurse on the branch with lower variance, accumulating conditions c. When a stopping criterion is met (min samples, low variance), create a rule with a linear model fitted to the covered instances d. Remove covered instances and repeat
  1. Instances not covered by any rule receive the global mean prediction

Theory

The splitting criterion uses Standard Deviation Reduction (SDR):

\text{SDR}(S, A) = \sigma(S) - \sum_{v} \frac{|S_v|}{|S|} \sigma(S_v)

where \sigma(S) is the standard deviation of the target in set S, and S_v are the subsets after splitting on attribute A.

At each leaf, a ridge-regularized linear model is fitted:

\hat{y} = X \beta + \beta_0, \quad \beta = (X^T X + \lambda I)^{-1} X^T y

where \lambda is a small regularization constant to ensure numerical stability.

Notes

Complexity:

  • Training: O(n \cdot m \cdot \log(n) \cdot r) where n
= number of samples, m = number of features, and r = number of rules generated
  • Prediction: O(r \cdot m) per sample (first matching rule)
When to use M5ModelRulesRegressor:
  • Regression tasks requiring interpretable IF-THEN rules
  • When piecewise linear relationships are expected
  • Datasets with heterogeneous subregions needing different linear models
  • When a balance of accuracy and interpretability is desired

Basic usage for rule-based regression:

python 
>>> from tuiml.algorithms.rules import M5ModelRulesRegressor
>>> import numpy as np
>>>
>>> # Create sample data
>>> X_train = np.array([[1], [2], [3], [4], [5]], dtype=float)
>>> y_train = np.array([1.1, 2.0, 3.1, 4.0, 5.2])
>>>
>>> # Fit the model
>>> reg = M5ModelRulesRegressor(min_samples_leaf=2)
>>> reg.fit(X_train, y_train)
M5ModelRulesRegressor(...)
>>> predictions = reg.predict(X_train)
>>> rules = reg.get_rules()
