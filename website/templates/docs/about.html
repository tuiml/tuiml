About TuiML

An agent-native ML runtime, developed at the AI Institute, University of Waikato.

What is TuiML?

TuiML is the agent-native ML runtime: classical machine learning that AI agents can actually call. Every algorithm, dataset, and metric ships with a JSON schema so agents can discover, invoke, and interpret results without hallucinated parameters or wrapper glue.

Three Pillars

Agents can call it

JSON schemas on every algorithm. No hallucinated parameters, no wrapper glue.

Agents can discover it

Queryable registry of algorithms tagged by task, data shape, and benchmarks.

Agents can trust it

Deterministic, reproducible, loggable tool calls. Production-safe.
