class algorithms.ensemble.random_committee.RandomCommitteeClassifier(Classifier)

RandomCommitteeClassifier ensemble classifier.

Builds an ensemble of randomizable base classifiers, each with a different random number seed. Diversity is achieved through the internal randomness of the base learners, as each member is trained on the full dataset.

RandomCommitteeRegressor

class algorithms.ensemble.random_committee.RandomCommitteeRegressor(Regressor)

RandomCommitteeRegressor ensemble regressor.

Builds an ensemble of randomizable base regressors, each with a different random number seed. Diversity is achieved through the internal randomness of the base learners, as each member is trained on the full dataset.
Constructor 
__init__(
    self,
    base_regressor: Any = 'AdditiveRegression',
    n_estimators: int = 10,
    random_state: Optional[int] = None,
    n_jobs: int = 1,
)

Overview

The algorithm proceeds as follows:

  1. For each of T committee members:
a. Create a base regressor with a unique random seed b. Train the regressor on the full training set
  1. To predict, average predictions from all T regressors

Theory

Given T base regressors h_1, \ldots, h_T each trained with a different random seed on the same data:

H(x) = \frac{1}{T} \sum_{t=1}^{T} h_t(x)

Diversity arises solely from the stochastic nature of each base learner (e.g., random feature selection in tree construction), not from data perturbation.

Parameters

base_regressor
str or class = 'AdditiveRegression'
The base regressor to use. Should be randomizable (i.e., its behaviour depends on a random seed).
n_estimators
int = 10
The number of committee members (base regressors).
random_state
int or None = None
Base random seed used to generate seeds for committee members.
n_jobs
int = 1
The number of jobs to run in parallel. -1 means use all processors.

Attributes

estimators_
list
The collection of fitted base regressors.

Notes

Complexity:

  • Training: O(T \cdot C_{\text{base}}) where T = n_estimators
  • Prediction: O(T \cdot C_{\text{predict}}) per sample
When to use RandomCommitteeRegressor:
  • When the base learner has internal randomness (e.g., random trees)
  • When you want ensemble diversity without bootstrap sampling
  • When all training data should be used for every committee member

python 
>>> from tuiml.algorithms.ensemble import RandomCommitteeRegressor
>>> import numpy as np
>>>
>>> # Create sample training data
>>> X_train = np.array([[1, 2], [2, 3], [3, 1], [4, 3], [5, 2]])
>>> y_train = np.array([1.5, 2.3, 3.1, 4.2, 5.0])
>>>
>>> # Fit the Random Committee regressor
>>> reg = RandomCommitteeRegressor(n_estimators=10, random_state=42)
>>> reg.fit(X_train, y_train)
RandomCommitteeRegressor(...)
>>> predictions = reg.predict(X_train)
