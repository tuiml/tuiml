Shared machinery for the CapyMOA (streaming) bridge.

CapyMOA exposes incremental (instance-at-a-time) learners. These wrappers adapt that streaming API to TuiML's batch fit / predict interface by iterating the rows of the input arrays, while still registering each learner into the hub under a capymoa. key.

CapyMOA is an optional dependency (it pulls in a JVM via moa). Importing this module never requires it; the dependency is checked at fit time with a clear, actionable error.
