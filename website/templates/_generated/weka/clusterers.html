Canopy

class weka.clusterers.Canopy(_WekaClustererMixin, Clusterer)

Canopy — cheap approximate pre-clustering (hub key weka.Canopy).

Wraps weka.clusterers.Canopy. Uses two distance thresholds to form overlapping "canopies" in a single cheap pass, normally as a seeding step for a more expensive algorithm.
Constructor 
__init__(
    self,
    n_clusters: int = ...,
    t2: float = ...,
    t1: float = ...,
    seed: int = 1,
    nominal_features: Optional[Sequence[int]] = None,
    options: Optional[Sequence[str]] = None,
)

Parameters

n_clusters
int = -1
Requested number of clusters (Weka -N); -1 lets the thresholds decide.
t2
float = -1.0
Loose distance threshold (Weka -t2); a negative value asks Weka to derive it from the data.
t1
float = -1.25
Tight distance threshold (Weka -t1); a negative value is interpreted as a multiple of t2.
seed
int = 1
Random seed (Weka -S).
nominal_features
sequence of int or None = None
0-based indices of columns to treat as categorical.
options
sequence of str or None = None
Extra raw Weka options.
