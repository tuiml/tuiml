class algorithms.ensemble.regression_by_discretization.RegressionByDiscretization(Regressor)

Regression by Discretization.

Converts a regression problem to classification by discretizing the target variable into bins, training a classifier, and then predicting continuous values using the predicted class probabilities and bin centers.
