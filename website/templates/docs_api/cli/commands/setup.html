setup

Line 638
setup(assume_yes: bool, force_manual: bool, list_only: bool, clients: tuple[str, Ellipsis]) -> None

Connect TuiML to your AI agents.

Detects installed clients and wires them up: appends an MCP server entry for MCP clients, copies the SKILL.md file for skill-based agents, or prints manual instructions for YAML/unsupported configs.

By default the wizard asks whether to configure every detected client at once (Auto) or one by one (Manual). Pass -y / --yes to skip the menu and go straight to Auto, or --manual to go straight to Manual.
