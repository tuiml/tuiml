Weka tree wrappers.

Decision and model trees from weka.classifiers.trees, registered under weka. hub keys so they sit alongside the native TuiML trees family without colliding with it.

Notes

Requires the optional Weka extra: pip install 'tuiml[weka]' plus a Java runtime (11+) on PATH.

class weka.trees.J48(_WekaSupervisedMixin, Classifier)

J48 — Weka's C4.5 decision tree (hub key weka.J48).

Wraps weka.classifiers.trees.J48, Weka's implementation of Quinlan's C4.5. Splits on the attribute with the highest gain ratio and prunes with subtree raising by default.

float = 0.25
Confidence threshold for pruning (Weka -C). Lower values prune more aggressively.
min_num_obj
int = 2
Minimum number of instances per leaf (Weka -M).

bool = False
Build an unpruned tree (Weka -U).

Use binary splits on nominal attributes (Weka -B).

sequence of int or None = None

class weka.trees.LMT(_WekaSupervisedMixin, Classifier)

LMT — Logistic Model Tree (hub key weka.LMT).

Wraps weka.classifiers.trees.LMT. A decision tree carrying a logistic regression model at each leaf, fitted with LogitBoost.
Constructor 
__init__(
    self,
    min_num_instances: int = 15,
    fast_regression: bool = True,
    nominal_features: Optional[Sequence[int]] = None,
    options: Optional[Sequence[str]] = None,
)

Parameters

min_num_instances
int = 15
Minimum instances at which a node is considered for splitting (Weka -M).
fast_regression
bool = True
Use the heuristic that speeds up LogitBoost fitting. Passing False emits Weka's -R flag to disable it.
nominal_features
sequence of int or None = None
0-based indices of columns to treat as categorical.
options
sequence of str or None = None
Extra raw Weka options.

Notes

LMT is considerably slower to train than J48, because every candidate node fits a boosted logistic model.
