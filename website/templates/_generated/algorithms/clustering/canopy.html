Canopy Clustering algorithm.

A fast, single-pass clustering algorithm that groups data into overlapping subsets (canopies) using two distance thresholds, T_1 (loose) and T_2 (tight). It is often used as a preprocessing step before applying more expensive clustering algorithms like K-Means.

Overview

The algorithm performs a single pass over the data:

  1. Shuffle the data randomly
  2. Pick the first available point and create a new canopy with it as center
  3. Add any point within distance T_1 to the canopy
  4. Remove any point within distance T_2 from the candidate list
  5. Repeat until all points are processed or the maximum canopy count is reached
Note that T_2 < T_1 is required for proper overlapping behavior.

Theory

Canopy clustering partitions data using two concentric distance thresholds around each canopy center c:

\text{member}(x, c) = \begin{cases} 1 & \text{if } d(x, c) \leq T_1 \ 0 & \text{otherwise} \end{cases}
\text{remove}(x, c) = \begin{cases} 1 & \text{if } d(x, c) \leq T_2 \ 0 & \text{otherwise} \end{cases}

The loose threshold T_1 determines canopy membership (allowing overlap), while the tight threshold T_2 prevents a point from becoming a future canopy center, ensuring separation between canopy centers.

Notes

Complexity:

  • Training: O(n \cdot k) where n is the number of samples
and k is the number of resulting canopies.
  • Space: O(k \cdot m) where m is the number of features.
When to use CanopyClusterer:
  • As a fast preprocessing step before K-Means or EM clustering
  • When you need approximate clustering with very large datasets
  • When overlapping cluster membership is acceptable
  • Streaming or single-pass clustering scenarios

Basic canopy clustering with explicit thresholds:

python 
>>> import numpy as np
>>> from tuiml.algorithms.clustering import CanopyClusterer
>>> X = np.array([[1, 2], [1.5, 1.8], [5, 5], [6, 4]])
>>> canopy = CanopyClusterer(t1=2.0, t2=1.0)
>>> canopy.fit(X)
>>> canopy.n_clusters_
2
>>> canopy.predict([[1.2, 1.9]])
array([0])
