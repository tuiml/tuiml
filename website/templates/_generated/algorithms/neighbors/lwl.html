LocallyWeightedLearningRegressor

class algorithms.neighbors.lwl.LocallyWeightedLearningRegressor(Regressor)

Locally Weighted Learning for regression using distance-based kernels.

LocallyWeightedLearningRegressor is an instance-based algorithm that assigns weights to training instances based on their distance to each query point. A local weighted linear regression model is then trained using these weighted instances to make a prediction for that specific point.

Also known as LWL (Locally Weighted Learning).

Overview

The algorithm operates in the following steps:

  1. Store and standardize all training instances during fit().
  2. For a new query x, compute the Euclidean distance to every
training instance in the standardized feature space.
  1. Select the k nearest neighbors (or use all instances if
k = -1).
  1. Compute a weight for each selected instance using the chosen kernel
function.
  1. Fit a weighted least-squares linear regression using the weighted
instances.
  1. Predict the target value for the query point using the local model.

Theory

The prediction for a query point x is obtained by solving the weighted least-squares problem:

\hat{\beta} = (X^T W X + \lambda I)^{-1} X^T W y
where:
  • X: Design matrix of (optionally selected) training instances
  • W: Diagonal matrix of kernel weights \text{diag}(w_1, \ldots, w_n)
  • y: Target vector
  • \lambda: Small ridge regularization term for numerical stability
Kernel functions:
  • Linear: w_i = \max(0,\; 1 - d_i / d_{\max})
  • Inverse: w_i = 1 / (d_i + \epsilon)
  • Gaussian: w_i = \exp(-d_i^2 / (2 \sigma^2))
where d_i = \|x - x_i\| and \sigma = d_{\max} / 3.

Parameters

k
int = -1
Number of nearest neighbors to use for local learning. If -1, all training instances are used.
weight_kernel
{'linear', 'inverse', 'gaussian'} = 'linear'

Kernel function used to calculate weights from distances:

  • •'linear': :math:`w = 1 - d / d_{\max}`
  • •'inverse': :math:`w = 1 / (d + \epsilon)`
  • •'gaussian': :math:`w = \exp(-d^2 / (2\sigma^2))`
use_all_attributes
bool = True
Whether to use all attributes for distance calculation.

Notes

Complexity:

  • Training: O(n \cdot m) for standardization, where n = samples, m = features
  • Prediction: O(n \cdot m + m^3) per query (distance computation plus weighted least-squares solve)
  • Space: O(n \cdot m) for storing training data
When to use LocallyWeightedLearningRegressor:
  • Non-linear regression problems where a global model is inadequate
  • When the relationship between features and target varies across
the feature space
  • Problems where local smoothness can be assumed
  • When interpretability at the local level (linear coefficients) is
useful

Locally weighted regression on a simple linear relationship:

python 
>>> from tuiml.algorithms.neighbors import LocallyWeightedLearningRegressor
>>> import numpy as np
>>> X = np.array([[1], [2], [3], [4]])
>>> y = np.array([2, 4, 6, 8])
>>> reg = LocallyWeightedLearningRegressor(k=2, weight_kernel='gaussian')
>>> reg.fit(X, y)
LocallyWeightedLearningRegressor(k=2, kernel='gaussian', n_train=4)
>>> reg.predict([[2.5]])
array([5.])
