Line 13
tuiml upload [OPTIONS]

Register a dataset so other TuiML commands can use it.

Validates a dataset and returns a canonical path you can hand to commands such as tuiml train, tuiml preprocess and tuiml profile. Supply either --file-path for a file already on disk (preferred, and the only practical option for large datasets) or --content with raw inline text plus --format. CSV, TSV, ARFF, Parquet, Excel, JSON, JSONL and NumPy npy/npz files are all supported.

Register a file that already exists on disk:

bash 
$ tuiml upload --file-path ./data/customers.csv

Register it under a friendlier name:

bash 
$ tuiml upload --file-path ./raw.parquet --name customers

Register a small dataset from inline text:

bash 
$ tuiml upload --content "$CSV_TEXT" --format csv --name demo

Options

--file-path
str
Path to an existing dataset file on disk. Supported: .csv, .tsv, .arff, .parquet, .pq, .xlsx, .xls, .json, .jsonl, .ndjson, .npy, .npz
--content
str
Raw text content for small inline datasets (use together with --format)
--format
str
File format of --content; ignored for --file-path, where it is inferred from the extension
--name
str
Name to register the dataset under (without extension)
--json-output
flag
Output raw JSON
