Weka meta-learner wrappers.

Ensemble and wrapper schemes from weka.classifiers.meta, registered under weka. hub keys. Every learner here takes a base learner, named by its fully-qualified Weka class.

Notes

Requires the optional Weka extra: pip install 'tuiml[weka]' plus a Java runtime (11+) on PATH.

Weka's command line nests a base learner's own options after a -- separator: 

-W weka.classifiers.trees.J48 -- -C 0.25 -M 2

_base_spec builds that tail, so a wrapper only needs base_classifier and base_options.

class weka.meta.Stacking(_WekaSupervisedMixin, Classifier)

Stacking — combine classifiers with a meta-learner (hub key weka.Stacking).

Wraps weka.classifiers.meta.Stacking. Trains several base classifiers, then trains a meta-classifier on their cross-validated predictions.
Constructor

    options: Optional[Sequence[str]] = None,

Parameters

classifiers
sequence of str or None = None
Fully-qualified Weka classes used as level-0 learners (Weka -B). Defaults to J48, NaiveBayes and IBk.
meta_classifier
str = "weka.classifiers.functions.Logistic"
Level-1 learner combining the base predictions (Weka -M).
num_folds
int = 10
Folds used to generate the level-1 training set (Weka -X).
seed
int = 1
Random seed (Weka -S).
nominal_features
sequence of int or None = None
0-based indices of columns to treat as categorical.
options
sequence of str or None = None
Extra raw Weka options.

Notes

num_folds matters more than it looks: the meta-learner only ever sees the level-1 table built from these folds, so too few folds starve it. On iris, dropping from the default 10 to 3 takes accuracy from 0.98 to 0.67. Lower it only when training cost forces you to.
