FilteredClassifier

class algorithms.ensemble.filtered_classifier.FilteredClassifier(Classifier)

FilteredClassifier meta-classifier.

Applies a filter (preprocessor) to the data before training, and then applies the same transformation before prediction. This enables seamless integration of data preprocessing and classification.
