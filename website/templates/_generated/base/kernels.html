class base.kernels.Kernel(ABC)

Abstract base class for kernel functions.

A kernel function K(x, y) computes the dot product of two instances in a (possibly high-dimensional or infinite) feature space without explicitly computing the feature mapping \phi:

K(x, y) = \langle \phi(x), \phi(y) \rangle

Kernels must satisfy Mercer's condition (positive semi-definite) to ensure valid behavior with SVMs.
