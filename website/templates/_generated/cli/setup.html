tuiml setup

Line 1038
tuiml setup [OPTIONS]

Connect TuiML to your AI agents.

Detects installed clients and wires them up: appends an MCP server entry for MCP clients, copies the SKILL.md file for skill-based agents, or prints manual instructions for YAML and unsupported configs. Every config file is backed up before it is modified, and re-running is safe: a client that is already wired correctly is left alone.

By default the wizard asks whether to configure every detected client at once (Auto) or one by one (Manual). Pass -y / --yes to skip the menu and go straight to Auto, or --manual to go straight to Manual. Undo everything with tuiml uninstall.

Run the interactive wizard:

bash 
$ tuiml setup

See which clients are detected, without changing anything:

bash 
$ tuiml setup --list

Wire up every detected client without prompting:

bash 
$ tuiml setup --yes

Configure only specific clients:

bash 
$ tuiml setup --client claude-code --client cursor

Options

--yes, -y
flag
Auto mode: configure every detected client without prompting.
--manual
flag
Manual mode: ask before configuring each client, skipping the Auto/Manual menu.
--list
flag
List the detected clients and their config paths, then exit without changing anything.
--client
repeatable
Configure only this client, by ID. Repeatable. Run 'tuiml setup --list' to see valid IDs.
