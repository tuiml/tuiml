Line 10
tuiml stop-server [OPTIONS]

Shut down a background model serving API server.

Stops a server started in the background by serve, and reports which servers were shut down. Without --server-id every running TuiML server is stopped. A foreground tuiml serve process is stopped with Ctrl-C instead.

Stop one specific server:

bash 
$ tuiml stop-server --server-id srv_abc123

Stop every running server:

bash 
$ tuiml stop-server

Options

--server-id
str
ID of the server to stop. Omit to stop every running TuiML server.
--json-output
flag
Print the raw JSON result.
