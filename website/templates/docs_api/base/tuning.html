ParameterGrid

class base.tuning.ParameterGrid

Cartesian product of parameter values for exhaustive search.

Generates every possible combination of parameter values defined in the search space.
Constructor

    self,
    param_grid: Union[Dict, List[Dict]],

Parameters

param_grid
dict or list of dict
A dictionary where keys are parameter names and values are lists of settings to try. Alternatively, a list of such dictionaries to define disjoint search spaces.

Examples

Exhaustively search a support vector machine space:

PYTHON 
>>> from tuiml.base import ParameterGrid
>>> grid = ParameterGrid({'C': [1, 10], 'kernel': ['linear', 'rbf']})
>>> len(grid)
4
>>> list(grid)[0]
{'C': 1, 'kernel': 'linear'}

ParameterDistribution

class base.tuning.ParameterDistribution

Distribution of parameters for random search.

Constructor 
__init__(
    self,
    param_distributions: Dict,
)

Parameters

param_distributions
dict

Dictionary with parameters as keys and distributions as values. Values can be:

  • •List: uniform choice from list
  • •Tuple (low, high): uniform continuous
  • •Tuple (low, high, 'log'): log-uniform
  • •Callable: distribution that returns a sample

Examples

PYTHON 
>>> from tuiml.base import ParameterDistribution
>>> dist = ParameterDistribution({
...     'C': (0.1, 10, 'log'),      # Log-uniform between 0.1 and 10
...     'kernel': ['linear', 'rbf'], # Uniform choice
...     'gamma': (0.001, 1)          # Uniform continuous
... })
>>> sample = dist.sample()

class base.tuning.BaseTuner(ABC)
