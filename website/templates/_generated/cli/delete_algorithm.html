tuiml delete-algorithm: remove a user-authored algorithm from disk.

Thin CLI wrapper over the tuiml_delete_algorithm tool. It deletes one version or the whole algorithm directory under ~/.tuiml/user_algorithms/.

tuiml delete-algorithm [OPTIONS]

Delete a user-authored algorithm from disk.

Pass only --name to remove every stored version of the algorithm, or add --version to remove a single one. Deletion is permanent: the files under ~/.tuiml/user_algorithms/ are gone, so keep a copy of anything you may want back.

Classes that are already loaded stay in the component registry of a running process; a live MCP server keeps serving them until it restarts (tuiml restart).

Requires TUIML_ALLOW_USER_ALGORITHMS=1 in the environment.

Remove every version of an algorithm:

bash 
$ tuiml delete-algorithm --name MyKNN

Remove one version and keep the rest:

bash 
$ tuiml delete-algorithm --name MyKNN --version 1.0.0

Delete a version and inspect the raw result:

bash 
$ tuiml delete-algorithm --name MyKNN --version 1.0.0 --json-output

Options

--name
str required
User algorithm name (directory name / class name).
--version
str
Version to delete, e.g. 1.0.0. If omitted, all versions are removed.
--json-output
flag
Print the raw JSON result.
